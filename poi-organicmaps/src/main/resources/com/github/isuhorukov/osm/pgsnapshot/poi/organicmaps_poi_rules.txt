# Adjustments of Organic Maps POI types for the is.poi tag.
# By default a type is a POI when it belongs to the POI classes of Organic Maps IsPoiChecker
# (libs/indexer/ftypes_matcher.cpp) and data/categories.txt has an entry for it.
# A rule applies to the type and its subtypes: amenity-parking also matches amenity-parking-fee.
#   +<type> [category ...] [!category ...] [key=value;value ...]
#                                                  POI, optionally with additional displayed categories,
#                                                  !category - without this category of Organic Maps,
#                                                  only for objects with one of the values of the tag,
#                                                  key=* - with any value of the tag
#   -<type>                  not a POI
#   -<type> key=value;value  not a POI for objects with one of the values of the tag, stronger than any + rule;
#                            key=* - with any value of the tag, several rules of one type are alternatives
# A type excluded by a -<type> rule without a tag also removes the other types of the object with the same two
# first levels, except the types included by a + rule below that - rule:
# amenity-parking-private removes amenity-parking-fee, tourism-information-board keeps tourism-information-office.
# Every POI type has a category: the classes of reach are built from them. Only the most specific + rule gives categories,
# so a type has one line, and a shop type without its own line gets the categories of the shop rule.
